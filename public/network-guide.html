01 / 设备

三台设备，各有规则

本机专用规则

Mac

没有命中直连例外的网站走所选代理。UU 远程、荣耀投屏、局域网及 Tailscale 等有直连规则。Claude 通过专用 Edge 或项目启动器使用固定线路。

iPhone 订阅

iPhone

没有命中直连例外的网站走所选代理；Claude 相关域名走固定线路。Clash Mi 要使用「内置-不覆写」和规则模式，并保持连接。

电脑订阅

Windows

先按明确的网站例外判断，再查国内域名和 IP 清单；仍未命中的连接走所选代理。订阅本身不代表已安装 Mac 的 Claude 专用保护。

02 / 线路

换节点，不等于换 Claude

只用 VPS

连接选中的自建 VPS，网站看到该 VPS 的出口 IP。Legend 和 ByteVirt 可在 Clash 的「VPS 节点」中选择。

VPS ＋ Webshare

先经过所选 VPS，再经过 Webshare；最终出口是 Webshare。

只用机场 / 机场＋Webshare

使用已启用的机场节点。机场停用后，网站保留订阅资料，但不会继续向设备下发它的节点。

Claude 固定线路单独保存。切换普通网站使用的节点不会自动更新 Claude；若要更换 Claude 出口，请到 Claude 设置单独操作。

03 / 网站例外

只为需要特殊处理的网站添加

直连例外优先于设备的普通默认规则。

在「网站例外」输入域名，选择直连或代理并保存。域名规则包含其子域名；一个网站可能使用多个不同域名，视频和图片不一定跟主站相同。

04 / 更新设备

网站改完后怎么生效

修改网站例外

保存后发布规则，客户端按规则集更新间隔拉取；也可以在 Clash 中手动刷新规则。

增加、停用或更换线路

在「线路管理」保存并发布，再到设备刷新已有订阅。停用节点后，如果设备此前选中了它，需重新选择。

iPhone 更新后

在 Clash Mi 更新现有订阅；若节点列表仍是旧的，重新连接 Clash Mi，再检查规则模式与所选节点。

05 / 了解 DNS

直连和查地址是两件事

DNS 负责把网址查询成地址。Mac 的默认查询走所选代理；iPhone 的默认查询走 Claude 固定线路；Windows 的直连和国内域名使用国内 DNS。因此，网站连接虽然是直连，也可能因为查询方式不同而拿到不同的服务器地址。

本页介绍配置原则；不显示设备实时连接，也不保证任何账号的登录或生成状态。
