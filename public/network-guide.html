网络管理设备上网线路管理网站规则Claude

使用帮助

连接 Wi-Fi，在网页选择线路。

家庭设备的日常操作集中在「设备上网」。新设备先正常联网，按需要切换；已安装客户端的设备保留原有订阅入口。

新设备怎么接入

  1. 1

    连接专用 Wi-Fi

    新设备默认家庭宽带直连。保留设备自动获取 IP 与 DNS 的设置。

  2. 2

    在网页找到这台设备

    从家庭局域网打开「设备上网」，用现有管理密码解锁。可按名称、IP 或 MAC 搜索。

  3. 3

    选择新加坡分流或家庭宽带

    选择即发起切换。首次接入如果仍使用原线路，断开并重连一次 Wi-Fi；之后只需在网页改线路。

设备管理仅在家庭局域网入口开放。外部域名不会提供这个控制页面。

打开设备上网

线路名称怎么选

线路用途支持范围
家庭宽带直连使用家庭宽带出口。已接入网关的设备仍由网关转发。新设备与已接入设备
新加坡分流 · SG按分流规则处理连接，代理流量使用新加坡线路。可自动接入的专用 Wi-Fi 设备与已支持设备
洛杉矶固定出口 · LA使用已部署的洛杉矶固定出口方案。仅已支持的设备；新设备选项会显示“暂未开放”

怎样看是否生效

规则已应用：网关确认保存的方案已执行。已观察到流量：网关观察到了这台设备的报文。二者都不是公网 IP 的自动检测结果。

等待设备流量：规则已准备，但尚未观察到相应流量。首次接入可重连 Wi-Fi、打开网页后刷新列表。

在设备上检查出口后，可在设备「详情」中记录实测通过。记录是该版本方案的历史验收，切换方案后需要重新核对。

其他功能

仍在使用 Clash / Mihomo 客户端

在「线路管理」维护订阅、VPS 与节点。客户端按自己的更新周期拉取配置，也可手动刷新。通过 Q4 网关接入的设备无需额外安装客户端或导入订阅。

给某个网站指定直连或代理

在「网站规则」中添加例外。域名规则包含子域名；视频、图片等资源可能使用其他域名。已接入规则提供器的客户端或网关会按各自的更新周期读取。

Claude 专用出口

在「Claude」中维护独立保存的专用配置。普通设备线路切换不会自动部署或替换专用客户端、本机保护或账号认证。

设备不在“可管理”中

先确认它连接了专用 Wi-Fi，再刷新或查看「全部」。其他 Wi-Fi、有线基础设备以及未授权设备不会自动接管，页面会显示原因。
