Claude 在独立工作区自动编辑，越界先申请

打开「Claude 项目启动器」，先准备独立工作区，再选择启动。副本从已提交代码创建，未提交改动和未跟踪文件不会复制。目录内使用自动编辑；项目外文件工具触发原生弹窗，显示读取或读写范围，批准后重启并恢复本次会话。拒绝不放行；退出后重新启动需要重新申请。

Shell 内部的任意文件访问不能靠 Hooks 全面识别，仍由外层系统限制阻止。授权不会改变网络限制。尚未注册也可先准备副本；真实编辑、登录和生成仍需本人验收。

普通远程开发正常，受限 Claude 内 SSH 会被阻止

已补上旧限制允许 Unix socket 的缺口：受限子进程不能访问 Clash 本地控制 socket，也不能复用外部 SSH 连接。普通 Terminal、Codex 和 Mutagen 不在这层 Claude 限制里。

如果 Claude 在 WSL 中运行，实际发请求的是 WSL；Mac 的 LuLu 无法保护远端。需要先给 WSL 设计独立出口限制。当前 macOS 方案也不是虚拟机隔离，不能承诺绝对无法逃逸。
