# 电脑订阅 DNS 分流

- NAS 镜像：`ghcr.io/pygmalion03/004-route-policy-hub:sha-b162ab7`；上一版 `sha-84500c0` 可用于回滚。保留原 Compose、环境变量和数据目录。
- 电脑订阅按现有规则提供器选择 DNS：手动直连、手动代理、国内域名依次优先；其余使用原默认 DNS。国内查询通过国内 DoH 直连。
- 当前 Mac 专用脚本移除这三项 DNS 策略并保留原 DNS，与 Mac 默认代理的特殊规则一致。脚本已安装并重新激活。
- iPhone 订阅继续使用原 Claude 固定 DNS 和域名规则，未调整手机配置。
- Windows 此前的临时 DNS 合并已移除；当前运行配置保留到下一次加载。刷新已有 Route Hub 订阅后由网站下发 DNS 策略；自动更新间隔为 60 分钟。

验证：`pnpm lint`、`pnpm build` 与 DNS 定向测试通过；WSL 独立容器验证电脑和手机订阅、两份规则端点、未认证写入拒绝及认证后无效写入进入校验。真实 NAS 电脑 / 手机订阅符合预期，两个局域网规则端点返回 200、未认证写入返回 401；公网订阅与规则端点使用 Clash 请求头返回 200。Mac 默认代理及 Claude 固定出口检查通过。尚未在真实 NAS 使用管理密码执行写入，也未在手机实机刷新订阅。
