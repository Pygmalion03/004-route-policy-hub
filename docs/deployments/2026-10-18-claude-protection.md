# Claude 专用网络与日常直连清单

本轮将 Claude Code 与日常使用方案分开：现有 17897 保持跟随日常方案，新增 17997 直接绑定独立保存的 VPS → Webshare 节点。日常切换或替换连接参数不覆盖专用副本；更换固定出口需在首页明确重新发布。

国内直连页只提供域名添加和移除；保留已有其他策略及只读规则端点。管理写入沿用密码鉴权，连接与策略数据只写 DATA_DIR。

## 已完成的隔离环境验收

- `pnpm lint`、`pnpm build` 通过。
- 官方 Mihomo 独立内核加载实际节点，切换只用 VPS、机场＋Webshare、VPS＋Webshare，专用出口保持不变。
- 日常 Webshare 参数修改不覆盖专用副本。
- 专用前置失效、代理内核停止、出口与预期不符时，启动器拒绝启动；前置恢复后出口检查恢复。测试未关闭用户生产 Clash 或实际断开 Wi-Fi。
- macOS 网络限制实际阻止子进程连接外部 IPv4、IPv6、UDP 和另一普通本地代理端口。
- 官方原生 Claude Code 2.1.292 安装并通过签名检查，在限制下运行版本命令成功。
- 预览浏览器真实执行域名 URL 添加、规范化保存及移除；只读规则对应更新。

浏览器额外套用 macOS 沙箱会与 Chrome 自身子进程沙箱冲突，未采用禁用 Chrome 沙箱的办法。浏览器系统层防护仍待用户选择与批准；页面不提供已验收的浏览器启动入口。没有进行 Claude 账号登录或实际生成，因此不宣称账号可用或不会被限制。

## 生产接入

首次升级曾将现有入口名称改为「现有 AI 出口」，触发 Mihomo 按名称更新 listener 时的同端口冲突；保护脚本恢复原运行配置。对照官方 v1.19.32 `PatchInboundListeners` 实现定位后恢复原名称「AI 专用出口」，避免不必要的重绑定。修正后实际热加载保留日常方案与机场节点，17897 日常出口保持原 VPS，17997 核对为固定 Webshare；Anthropic 未认证接口与 Magpie 网关均返回 401。

网站正式管理会话已成功发布专用副本；国内直连界面简化上线。未认证连接和直连写入均返回 401。真实节点与运行证据只保存在忽略目录中。
